## 覆蓋及邊界

兩域各11項 unit interaction：列表 Link 導航、exact URL 與 returnTo、page3 Back/Forward、direct/copied URL 用新 QueryClient 重新讀相同 ID、第二 ID 不殘留第一個 record、slash list、空態、非法 ID 零讀取、missing 無錯誤重試、403/503 explicit retry、pending departure 忽略晚回應，以及 unsafe returnTo 收斂。

兩域各5項 browser scenario：鍵盤 Enter 開案→Back→Forward→真正 `page.reload()`；精確返回 anchor 與第二 ID；stub 403/503→explicit retry、missing、malformed；離開 pending detail 及晚回應；slash／empty。reload 前修改的只是本輪 sessionStorage stub 記錄，reload 由新 QueryClient 再呼叫 stub，註冊地址 `QA reload readback`／變更報價 `HKD 9,160` 可見，每域 reads 2→3。不是 DB 持久化、原生 HTTP 或付款金額驗收。

Final green2 每域第6項補同案重複導航，pending transport reads 保持1；再開另一 ID 並先釋放第二案回應，最後釋放第一案回應，仍保持第二案 DOM／URL，2次讀取精確對應兩個不同 ID。這是讀取／導航的並發回歸，不代替其他 UC 的付款／寫入冪等驗收。

真實讀取授權 policy 的 unit 回歸同跑；browser 的角色拒絕是 stub rejection UI handling，不是 Auth/RLS 證據。取消範圍是放棄載入中的頁面，沒有取消業務案件。此讀取旅程不做付款、filing、案件狀態／清單 mutation；其冪等／並發另有原編號 evidence。

Runtime 只掛這4個實際 route modules，按 generated route tree 的兩組父子關係組合；root/auth guard 是測試 context，完整 production root、原生登入與伺服器 transport 未驗。無 DB target／client／migration／seed／SQL cleanup。Fixtures 只屬本輪 fresh browser context，ID `e4b761c9-0160-4160-8160-000000000001/2`，context 關閉後不保留業務資料；cache 原位保留。Native matrix 保留70 BLOCKED／114 NOT_RUN／0 PASS、release NO_GO。
