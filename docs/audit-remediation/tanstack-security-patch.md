# B01 — TanStack Start security patch

Main baseline: `aa5d3cbddd895bca953b6eef7266ae1cc0b46215`. This independent patch does not contain candidate audit migrations.

## Contract and source

PR07's Vercel preview `dpl_DW2wY4sScxgm9UuYh8gHKhEfNqMD` built successfully, then failed the platform security gate for installed `@tanstack/react-start@1.168.26`.

[Official advisory GHSA-qx66-fv34-fjm8](https://github.com/TanStack/router/security/advisories/GHSA-qx66-fv34-fjm8) identifies CVE-2026-102989 and the first patched React Start `1.168.60` / server core `1.169.39`. Pin Start to that release and align the direct React Router to Start's exact `1.170.41` dependency. Preserve Lovable's Vite configuration, server authorization and CSRF middleware.

Align Router Plugin to Start Plugin Core's exact `1.168.42` dependency to avoid retaining a second generator/core version. Transitive Babel, serialization and generator dependencies follow the upstream patched packages; this is not a blanket application dependency update. The generated route tree is regenerated by the existing plugin.

The patch was published on 2026-09-30, beyond the existing 24-hour dependency cooldown when installed on 2026-10-02. No cooldown exclusion or vulnerable deployment bypass is permitted.

## Release and rollback

Release owner must review this main-based patch, exact lockfiles, full gates and platform preview before a production release. No database migration is required by this patch. Production merge/deployment has not been performed or newly authorized.

The audit stack receives the same source patch by additive cherry-pick and reruns its own gates. It remains a distinct release with candidate migrations and runtime acceptance gates.

Rollback should pause release and restore the last approved **patched** build. Restoring the vulnerable baseline reintroduces this security defect and requires an explicit incident decision with exposure controls; do not set Vercel's vulnerable-package bypass to force deployment.
