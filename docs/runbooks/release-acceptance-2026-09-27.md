## Rollout and abort

Release 1 is read-only correctness and compatibility; Release 2 is monthly import and manual filing pilot; Release 3 is approved provider messaging; Release 4 is Admin/bulk/AI/scale per capability. Every stage binds one commit SHA, deployment ID, schema ledger, provider revision, role matrix and rollback reference. Stop at any missing gate. On a failed write migration, stop consumers and use the named pre-change snapshot in an isolated restore rehearsal; on an unknown external send or filing outcome, preserve records and reconcile with the provider before further action.
